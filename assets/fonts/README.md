# Font self-hosted

- `work-sans-latin.woff2`: Work Sans, font variabile (peso 200-500), sottoinsieme latino. Licenza: SIL Open Font License 1.1 (`OFL-WorkSans.txt`).
- `jetbrains-mono-latin.woff2`: JetBrains Mono 400, sottoinsieme latino. Licenza: SIL Open Font License 1.1 (`OFL-JetBrainsMono.txt`).

File presi dalla CDN di Google Fonts (v24 di entrambe le famiglie) il 15/09/2026 e serviti da qui: nessuna richiesta a Google dal browser del visitatore. Le regole `@font-face` stanno in testa a `assets/baboo.css`; il preload è nell'`<head>` di ogni pagina.
